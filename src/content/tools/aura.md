# Aura란?

Aura는 AI로 랜딩 페이지와 웹사이트 디자인을 빠르게 생성하는 웹 디자인 빌더입니다.

텍스트 프롬프트, 이미지, 기존 디자인 아이디어를 바탕으로 페이지 초안을 만들고, 결과물을 HTML, Tailwind CSS, Figma 형태로 내보낼 수 있습니다.

핵심은 "아이디어를 시각적인 웹 페이지 초안으로 빠르게 바꾸는 것"입니다. 완성된 프로덕션 웹앱을 대신하기보다는, 랜딩 페이지 콘셉트와 마케팅 사이트 디자인을 빠르게 탐색하는 데 잘 맞습니다.

---

# Aura의 핵심 특징

Aura는 일반적인 템플릿 편집기보다 AI 생성과 코드 내보내기에 초점이 있습니다.

프롬프트로 페이지 방향을 잡고, 생성된 화면을 수정한 뒤, HTML과 Tailwind CSS 또는 Figma 작업물로 이어갈 수 있습니다.

## AI 기반 페이지 생성

사용자는 만들고 싶은 서비스, 톤, 섹션 구성, 컬러 방향 등을 입력해 랜딩 페이지 초안을 생성할 수 있습니다.

빈 캔버스에서 시작하는 부담을 줄여주기 때문에 초기 기획, 디자인 레퍼런스 제작, 빠른 콘셉트 검토에 유용합니다.

### 활용 예시

- 스타트업 랜딩 페이지 초안 제작
- 제품 소개 페이지 콘셉트 탐색
- SaaS 서비스 히어로 섹션 생성
- 캠페인 페이지 디자인 시안 제작
- Figma로 넘길 웹 디자인 베이스 생성
- Tailwind CSS 기반 HTML 프로토타입 제작

---

## HTML과 Tailwind CSS export

Aura는 생성된 디자인을 HTML과 Tailwind CSS 기반 코드로 내보낼 수 있습니다.

디자이너는 시각적인 결과물을 만들고, 개발자는 이를 참고해 실제 프로젝트 구조에 맞게 컴포넌트화할 수 있습니다.

다만 export 결과는 바로 서비스에 배포하기보다는, 레이아웃 구조와 스타일 방향을 빠르게 잡는 시작점으로 보는 편이 좋습니다.

---

## Figma 연동

Aura는 생성한 결과물을 Figma로 이어갈 수 있어 디자인 팀의 기존 워크플로우와 연결하기 쉽습니다.

AI로 만든 초안을 Figma에서 다시 다듬고, 컴포넌트, 오토레이아웃, 디자인 시스템 규칙에 맞게 정리하는 방식으로 활용할 수 있습니다.

---

## 템플릿과 프롬프트 빌더

Aura는 다양한 웹 디자인 템플릿과 프롬프트 생성 흐름을 제공합니다.

처음부터 문장을 모두 작성하지 않아도 업종, 목적, 섹션, 스타일을 조합해 결과를 만들 수 있어 빠른 실험에 적합합니다.

---

# Aura의 장점

## 1. 랜딩 페이지 아이디어를 빠르게 시각화한다

서비스 설명이나 캠페인 메시지만 있는 상태에서도 웹 페이지 형태의 초안을 만들 수 있습니다.

기획자, 디자이너, 창업팀이 같은 화면을 보며 방향을 논의하기 좋습니다.

---

## 2. 디자인과 코드 사이를 가볍게 연결한다

Figma와 HTML, Tailwind CSS export를 지원하기 때문에 결과물을 디자인 파일이나 개발 참고 코드로 이어갈 수 있습니다.

완성 코드 자동화보다는 디자인 핸드오프와 프로토타이핑 속도를 높이는 쪽에 강점이 있습니다.

---

## 3. 웹 디자인 레퍼런스 제작에 유용하다

여러 버전의 히어로 섹션, 기능 소개, 가격표, CTA 영역을 빠르게 뽑아 비교할 수 있습니다.

초기 방향을 좁히는 데 시간을 줄여주고, 이후 세부 디자인 작업에 집중할 수 있게 해줍니다.

---

# 주의할 점

Aura는 웹사이트 디자인 초안과 export에는 강하지만, 복잡한 제품 로직이나 운영 기능까지 자동으로 완성하는 도구는 아닙니다.

실제 서비스에 사용하려면 반응형 품질, 접근성, SEO, 성능, 컴포넌트 구조를 별도로 점검해야 합니다.

또한 AI가 만든 레이아웃은 브랜드 톤, 정보 우선순위, 실제 콘텐츠 길이에 맞춰 사람이 다시 다듬어야 완성도가 올라갑니다.

---

# Aura는 어떤 사람에게 적합할까?

- 랜딩 페이지 초안을 빠르게 만들고 싶은 창업팀
- 디자인 시안을 짧은 시간 안에 여러 개 비교해야 하는 디자이너
- Figma로 가져갈 웹 디자인 베이스가 필요한 팀
- Tailwind CSS 기반 HTML 구조를 참고하고 싶은 개발자
- 마케팅 페이지와 캠페인 페이지를 자주 실험하는 팀
- AI 웹 디자인 도구의 결과물을 빠르게 검토하고 싶은 사용자

---

# 마무리

Aura는 프롬프트 기반 웹 디자인과 export 흐름을 결합한 AI 사이트 빌더입니다.

아이디어를 랜딩 페이지 형태로 빠르게 만들고, Figma나 HTML, Tailwind CSS 작업으로 이어가고 싶은 팀에게 실용적인 출발점이 될 수 있습니다.
