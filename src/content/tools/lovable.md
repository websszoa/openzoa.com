# Lovable이란?

Lovable은 자연어로 풀스택 웹앱을 생성하고 수정할 수 있는 AI 앱 빌더입니다.

React 프론트엔드, Supabase 기반 백엔드, 인증, 데이터베이스, 배포 흐름을 함께 다루며 아이디어를 빠르게 작동하는 제품 형태로 바꾸는 데 초점이 있습니다.

---

# Lovable의 핵심 특징

## 자연어 기반 앱 생성

사용자는 만들고 싶은 기능과 화면을 설명하고, Lovable은 앱 구조와 UI, 기본 로직을 생성합니다.

비개발자도 초기 제품을 빠르게 만들어볼 수 있고, 개발자는 프로토타입을 바탕으로 실제 구현 방향을 검토할 수 있습니다.

### 활용 예시

- SaaS MVP 제작
- 내부 도구 프로토타입
- 데이터베이스가 필요한 웹앱 초안
- 인증과 CRUD 기능이 있는 서비스
- 프론트엔드와 백엔드 흐름 검토

---

## Supabase와 배포 흐름

Lovable은 데이터베이스, 인증, 파일 저장 같은 백엔드 기능을 Supabase와 연결해 구성할 수 있습니다.

아이디어 수준의 화면을 실제로 저장과 로그인까지 되는 앱으로 확장하기 쉽습니다.

---

# 주의할 점

AI가 만든 앱은 보안 규칙, 데이터 모델, 에러 처리, 접근성을 반드시 검토해야 합니다.

초기 검증에는 빠르지만, 운영 서비스로 키울 때는 코드 품질과 아키텍처를 개발자가 다시 정리하는 과정이 필요합니다.
