# Pencil이란?

Pencil은 IDE 안에서 동작하는 디자인 캔버스입니다.

픽셀 좌표, 디자인 토큰, 화면 구조를 AI 에이전트와 코드 작업 흐름에 전달해 디자인과 구현을 더 가깝게 연결하는 데 초점이 있습니다.

---

# Pencil의 핵심 특징

## IDE 안의 디자인 캔버스

Pencil은 별도 디자인 툴과 코드 에디터를 오가는 대신, 개발 환경 안에서 화면을 보고 수정하는 흐름을 제공합니다.

AI 에이전트가 디자인의 시각적 맥락을 읽고 코드 수정에 반영할 수 있도록 돕는 것이 핵심입니다.

### 활용 예시

- 프론트엔드 UI 구현 보조
- 디자인 토큰 기반 화면 수정
- 코드와 디자인의 양방향 확인
- AI 코딩 에이전트에 시각 컨텍스트 제공
- 컴포넌트 레이아웃 조정

---

## 코드와 디자인의 동기화

Pencil은 화면상의 위치, 크기, 스타일 정보를 코드 작업과 연결하려는 접근을 취합니다.

디자이너가 만든 정적 산출물을 개발자가 다시 해석하는 과정을 줄이고, 구현 중 발생하는 미세한 레이아웃 조정을 빠르게 처리할 수 있습니다.

---

# 주의할 점

Pencil은 기존 디자인 시스템과 코드 구조를 잘 이해하고 사용할 때 효과가 큽니다.

초기 도입 시에는 어떤 컴포넌트와 토큰을 기준으로 삼을지 팀 규칙을 먼저 정리하는 것이 좋습니다.
