# Zed란?

Zed는 Rust와 GPU 렌더링 기반으로 빠르게 동작하는 오픈소스 코드 에디터입니다.

실시간 협업, 고성능 편집, AI 기능을 결합해 현대적인 개발 워크플로우에 맞춘 편집 경험을 제공합니다.

---

# Zed의 핵심 특징

## 빠른 편집 성능

Zed는 속도와 반응성을 중요하게 설계된 에디터입니다.

큰 파일이나 여러 프로젝트를 다룰 때도 가볍게 동작하는 편이며, 개발자가 코드에 집중할 수 있는 간결한 인터페이스를 제공합니다.

### 활용 예시

- 빠른 코드 탐색과 편집
- 팀원과의 실시간 페어 프로그래밍
- AI 보조 코드 작성
- 대규모 프로젝트의 파일 탐색
- 터미널과 편집 작업 병행

---

## 협업과 AI

Zed는 멀티플레이어 편집 기능을 제공해 같은 프로젝트를 함께 보며 작업할 수 있습니다.

AI 기능도 에디터 안에서 사용할 수 있어 코드 설명, 수정, 생성 작업을 흐름 안에서 처리할 수 있습니다.

---

# 주의할 점

Zed는 빠르게 발전 중인 에디터이므로 확장 생태계나 세부 기능은 VS Code보다 부족할 수 있습니다.

기존 확장에 크게 의존하는 팀이라면 필요한 언어와 도구 지원을 먼저 확인하는 것이 좋습니다.
