# Sketch란?

Sketch는 macOS 네이티브 UI 디자인 도구입니다.

오랫동안 디지털 제품 디자인 분야에서 사용되어 왔으며, 심볼, 스타일, 라이브러리, 프로토타이핑 기능을 통해 앱과 웹 UI를 설계할 수 있습니다.

---

# Sketch의 핵심 특징

## macOS 네이티브 디자인 환경

Sketch는 Mac 앱으로 동작하기 때문에 빠른 반응성과 익숙한 데스크톱 작업 흐름을 제공합니다.

UI 화면, 아이콘, 컴포넌트, 디자인 시스템을 정리하는 데 필요한 기본기가 탄탄합니다.

### 활용 예시

- 웹과 모바일 앱 UI 디자인
- 디자인 시스템 라이브러리 관리
- 아이콘과 벡터 에셋 제작
- 클릭 가능한 프로토타입 구성
- 개발자 핸드오프 자료 정리

---

## 라이브러리와 협업

공유 라이브러리, 컴포넌트 관리, 클라우드 기반 피드백 기능을 통해 팀 단위 작업을 지원합니다.

최근에는 MCP 기반 AI 연동도 강화하며 기존 디자인 파일을 더 넓은 워크플로우와 연결하려는 방향을 보이고 있습니다.

---

# 주의할 점

Sketch는 macOS 중심 도구라 Windows나 Linux 사용자가 섞인 팀에서는 접근성이 제한될 수 있습니다.

브라우저 기반 실시간 협업이 중요한 팀이라면 Figma 같은 대안과 비교해보는 것이 좋습니다.
