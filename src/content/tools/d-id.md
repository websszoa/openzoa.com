# D-ID란?

D-ID는 이미지나 아바타에 음성과 표정을 더해 말하는 영상으로 변환하는 AI 디지털 휴먼 플랫폼입니다.

정적인 인물 이미지나 캐릭터를 활용해 설명 영상, 안내 영상, 인터랙티브 콘텐츠를 만들 수 있습니다.

---

# D-ID의 핵심 특징

## 말하는 이미지 생성

인물 이미지와 스크립트 또는 음성을 입력하면 입 모양과 표정이 움직이는 영상으로 만들 수 있습니다.

간단한 안내자, 캐릭터 설명, 프레젠터형 콘텐츠를 빠르게 제작할 때 유용합니다.

### 활용 예시

- 디지털 휴먼 안내 영상
- 캐릭터 기반 교육 콘텐츠
- 제품 설명용 아바타
- 챗봇과 연결된 영상 인터페이스
- 다국어 안내 콘텐츠

---

## API와 서비스 연동

D-ID는 플랫폼 기능뿐 아니라 API 기반으로 디지털 휴먼 경험을 제품에 연결하는 흐름도 지원합니다.

대화형 서비스나 고객 지원 경험에 응용할 수 있습니다.

---

# 주의할 점

인물 이미지 사용에는 초상권과 동의가 중요합니다.

실존 인물처럼 보이는 콘텐츠는 오해를 줄 수 있으므로 사용 목적과 표시 방식을 신중히 정해야 합니다.
