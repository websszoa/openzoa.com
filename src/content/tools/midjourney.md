# Midjourney란?

Midjourney는 텍스트 프롬프트를 바탕으로 고품질 이미지를 생성하는 AI 이미지 플랫폼입니다.

콘셉트 아트, 무드보드, 캠페인 비주얼, 제품 아이디어 탐색처럼 시각적 방향을 빠르게 넓히는 작업에 많이 쓰입니다.

---

# Midjourney의 핵심 특징

## 높은 시각 품질

Midjourney는 분위기, 조명, 질감, 구도 표현이 강한 이미지 생성에 강점이 있습니다.

초기 아이디어를 한 장의 강한 비주얼로 표현하거나 여러 스타일을 빠르게 비교할 때 효과적입니다.

### 활용 예시

- 브랜드 무드보드 제작
- 캠페인 콘셉트 이미지 생성
- 캐릭터와 배경 아이데이션
- 제품 비주얼 방향 탐색
- 프레젠테이션용 분위기 이미지 제작

---

## 프롬프트 기반 반복

텍스트 설명, 이미지 참조, 스타일 조정 값을 활용해 결과를 반복 개선할 수 있습니다.

디자인 초기 단계에서 "어떤 분위기가 맞는지"를 빠르게 확인하는 데 적합합니다.

---

# 주의할 점

생성 이미지가 실제 브랜드, 인물, 제품을 정확히 반영한다고 보기는 어렵습니다.

상업적으로 사용할 때는 라이선스, 권리, 실제 제품과의 일치 여부를 확인하고 후처리 과정을 거치는 것이 좋습니다.
