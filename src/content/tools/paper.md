# Paper란?

Paper는 캔버스의 요소가 실제 HTML과 CSS로 구성되는 코드 네이티브 디자인 툴입니다.

디자인 결과물을 구현과 분리된 목업으로 두기보다, 처음부터 웹 구조에 가까운 형태로 다루는 것이 특징입니다.

---

# Paper의 핵심 특징

## HTML과 CSS 기반 캔버스

Paper에서 배치하는 요소는 웹 기술과 가까운 구조를 갖습니다.

디자이너는 시각적으로 화면을 만들고, 개발자는 그 결과를 실제 웹 구현 관점에서 이해하기 쉽습니다.

### 활용 예시

- 웹사이트 레이아웃 설계
- 랜딩 페이지 초안 제작
- 반응형 구조 실험
- 코드 기반 디자인 시스템 검토
- AI 에이전트가 읽기 쉬운 디자인 자료 구성

---

## AI 에이전트 친화적 구조

Paper의 결과물은 실제 웹 요소에 가깝기 때문에 AI가 디자인을 읽고 수정하는 데 유리합니다.

픽셀 이미지보다 구조적 정보가 많아, 코드 생성이나 수정 흐름과 연결하기 쉽습니다.

---

# 주의할 점

코드 네이티브 접근은 웹 UI에는 강하지만, 자유로운 그래픽 작업이나 일러스트 중심 디자인에는 전통적인 디자인 툴이 더 편할 수 있습니다.

팀의 작업물이 웹 구현과 얼마나 가까운지에 따라 도입 효과가 달라집니다.
