# Wonder란?

Wonder는 AI 기반 디자인 캔버스에서 실제 React와 Tailwind CSS 코드를 생성하는 디자인 도구입니다.

디자인을 이미지나 목업으로 끝내지 않고, 코드베이스와 연결되는 화면 구조로 이어가려는 팀에 맞춰져 있습니다.

---

# Wonder의 핵심 특징

## 코드와 연결되는 디자인 캔버스

Wonder는 디자인 화면을 만들면서 구현 가능한 React 컴포넌트와 Tailwind 스타일을 함께 고려합니다.

AI가 디자인 의도를 코드 구조로 바꾸는 데 초점이 있어, 초기 UI 탐색과 프론트엔드 구현 사이의 반복을 줄이는 데 유용합니다.

### 활용 예시

- React 기반 화면 초안 제작
- Tailwind CSS 스타일 방향 탐색
- 디자인 시스템 기반 UI 생성
- 코드베이스와 연결된 화면 수정
- 디자이너와 개발자의 공동 프로토타이핑

---

## MCP 기반 연동

Wonder는 MCP를 통해 프로젝트 컨텍스트를 AI가 이해하도록 돕는 흐름을 지향합니다.

단순히 예쁜 화면을 생성하는 것보다 실제 코드 구조, 컴포넌트, 스타일 규칙과 맞는 결과를 만드는 데 초점이 있습니다.

---

# 주의할 점

AI가 생성한 코드는 프로젝트의 상태 관리, 접근성, 데이터 조건까지 완벽히 반영하지 못할 수 있습니다.

실서비스에 적용할 때는 기존 컴포넌트 규칙과 테스트 기준에 맞춰 다시 정리하는 과정이 필요합니다.
