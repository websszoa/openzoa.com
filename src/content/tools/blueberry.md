# Blueberry란?

Blueberry는 Mac에서 코드 에디터, 터미널, 브라우저 미리보기, 캔버스, 작업 앱을 한 창에 모아 사용하는 AI-native 제품 개발 워크스페이스입니다.

웹앱을 만들 때 자주 오가는 에디터, 터미널, 브라우저, 디자인 메모, 협업 앱을 한 화면 안에 배치하고, AI 코딩 에이전트가 이 전체 컨텍스트를 볼 수 있도록 설계되어 있습니다.

핵심은 "개발 도구를 따로 오가지 않고, AI가 현재 프로젝트 상황을 더 잘 이해하게 만드는 것"입니다.

---

# Blueberry의 핵심 특징

Blueberry는 단순한 코드 에디터라기보다, 제품 개발에 필요한 여러 작업 면을 하나의 프로젝트 워크스페이스로 묶는 데 초점이 있습니다.

코드 작성, 명령 실행, 화면 확인, 구조 스케치, 외부 앱 참조가 같은 흐름 안에서 이어집니다.

## 통합 개발 워크스페이스

Blueberry는 에디터, 터미널, 미리보기 브라우저, 캔버스를 한 창에서 함께 사용할 수 있습니다.

웹 개발 중 코드를 수정하고, 서버를 실행하고, 결과 화면을 확인하는 반복 작업을 같은 공간에서 처리할 수 있어 창 전환이 줄어듭니다.

### 활용 예시

- 웹앱 개발 환경 구성
- AI 코딩 에이전트와 함께 기능 구현
- 프론트엔드 화면을 보며 즉시 수정
- 터미널 로그와 브라우저 결과를 동시에 확인
- UI 플로우와 아키텍처를 캔버스에 스케치
- 프로젝트별 작업 레이아웃 저장

---

## AI 에이전트 컨텍스트

Blueberry는 Claude Code, Codex, Gemini CLI, OpenCode 같은 터미널 기반 AI 코딩 에이전트와 함께 쓰는 흐름을 지원합니다.

AI가 단순히 코드 파일만 보는 것이 아니라, 열려 있는 파일, 터미널 출력, 미리보기 브라우저, 캔버스, 고정 앱 같은 작업 상태를 함께 참고할 수 있도록 Blueberry MCP를 제공합니다.

이 구조는 "지금 화면에서 무슨 일이 일어나는지"를 AI에게 전달해야 하는 반복 설명을 줄이는 데 도움이 됩니다.

---

## 코드 에디터와 터미널

Blueberry의 에디터는 문법 강조, 검색과 치환, 멀티 커서, Git 연동 같은 기본 개발 기능을 제공합니다.

터미널은 여러 탭과 세션 지속성을 지원하며, 로컬 개발 서버를 감지해 미리보기 브라우저와 연결하는 흐름을 제공합니다.

---

## 미리보기 브라우저

내장 브라우저를 통해 로컬 웹앱을 바로 확인할 수 있습니다.

데스크톱, 태블릿, 모바일 화면을 확인하는 디바이스 프리뷰가 제공되어 반응형 UI를 점검하기 좋습니다.

터미널에서 로컬 서버가 실행되면 preview 패널로 이어지는 흐름도 Blueberry의 주요 장점입니다.

---

## 캔버스와 고정 앱

Blueberry에는 아이디어를 스케치하거나 UI 흐름, 아키텍처를 정리할 수 있는 캔버스가 포함되어 있습니다.

GitHub, Linear, Figma, PostHog 같은 외부 앱을 프로젝트별로 고정해두고, 개발 중 필요한 맥락을 한 화면 안에서 유지할 수도 있습니다.

---

# Blueberry의 장점

## 1. 창 전환을 줄인다

에디터, 터미널, 브라우저, 참고 앱이 따로 흩어져 있으면 작은 확인에도 집중이 끊기기 쉽습니다.

Blueberry는 웹앱 개발에 필요한 화면을 한 워크스페이스에 모아 반복적인 전환 비용을 줄입니다.

---

## 2. AI가 더 많은 작업 맥락을 본다

AI 코딩 도구는 컨텍스트가 부족하면 같은 설명을 반복해서 요구하거나 현재 화면 상태를 놓치기 쉽습니다.

Blueberry MCP는 프로젝트 파일뿐 아니라 터미널과 브라우저 상태까지 연결해 AI가 더 넓은 상황을 이해하도록 돕습니다.

---

## 3. 프로젝트별 작업 환경을 유지한다

프로젝트마다 필요한 터미널, 미리보기, 앱, 레이아웃이 다릅니다.

Blueberry는 프로젝트별 워크스페이스 구성을 저장해두고 다시 열 수 있어, 작업을 재개할 때 준비 시간이 줄어듭니다.

---

# 주의할 점

Blueberry는 현재 Mac 중심의 데스크톱 워크스페이스이기 때문에 Windows나 Linux 사용자는 바로 사용하기 어렵습니다.

또한 VS Code나 JetBrains IDE처럼 오랜 기간 축적된 확장 생태계와 세부 IDE 기능을 모두 대체한다고 보기는 어렵습니다.

가장 큰 장점은 "AI와 함께 웹앱을 만들 때 필요한 맥락을 한 곳에 모으는 것"이므로, 이미 기존 IDE와 터미널, 브라우저 조합에 깊게 익숙한 팀이라면 전환 비용을 고려해야 합니다.

---

# Blueberry는 어떤 사람에게 적합할까?

- Mac에서 웹앱을 만드는 개발자
- Claude Code, Codex, Gemini CLI 같은 AI 코딩 에이전트를 자주 쓰는 사용자
- 에디터, 터미널, 브라우저를 한 화면에서 관리하고 싶은 사람
- 프론트엔드 결과를 계속 보면서 빠르게 수정하는 팀
- 프로젝트별 작업 레이아웃을 저장해두고 싶은 개발자
- UI 아이디어와 구현 흐름을 캔버스에 함께 정리하고 싶은 빌더

---

# 마무리

Blueberry는 기존 IDE에 AI 채팅을 붙인 도구라기보다, AI 코딩 시대에 맞춰 개발 화면 전체를 하나의 컨텍스트로 묶으려는 제품 개발 워크스페이스입니다.

웹앱을 만들면서 코드, 터미널, 브라우저, 캔버스, 협업 앱을 계속 오가는 사용자라면 생산성 향상을 기대해볼 수 있습니다.
