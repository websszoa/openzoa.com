# Cavalry란?

Cavalry는 모션 디자이너와 애니메이터를 위한 2D 애니메이션 및 모션 그래픽 소프트웨어입니다.

After Effects처럼 키프레임 기반 애니메이션을 만들 수 있지만, 더 큰 차별점은 절차형 시스템, 데이터 기반 애니메이션, 실시간 뷰포트, 리깅과 인스턴싱을 2D 작업에 적극적으로 가져온다는 점입니다.

핵심은 "반복되는 모션 작업을 수작업으로 복제하지 않고, 규칙과 데이터로 제어하는 것"입니다.

---

# Cavalry의 핵심 특징

Cavalry는 일반적인 타임라인 애니메이션 툴과 procedural motion design 툴의 중간에 있습니다.

도형, 텍스트, 이미지, 데이터, 행동 노드를 연결해 반복적인 모션을 만들고, 결과를 실시간으로 확인하면서 다듬을 수 있습니다.

## Procedural animation

Cavalry의 가장 큰 특징은 절차형 애니메이션 워크플로우입니다.

복제, 변형, 리깅, 제약, 랜덤, 노이즈, 데이터 연결 같은 규칙을 조합해 한 번 만든 시스템을 여러 상황에 재사용할 수 있습니다.

### 활용 예시

- 반복 패턴이 많은 모션 그래픽 제작
- 키네틱 타이포그래피 애니메이션
- 데이터 기반 인포그래픽 영상
- 제너러티브 그래픽과 추상 모션
- 브랜드 시스템용 모션 템플릿
- 여러 규격의 광고 소재 자동 생성

---

## 실시간 뷰포트

Cavalry는 작업 결과를 실시간으로 확인하는 데 초점이 있습니다.

복잡한 장면을 만들 때도 변경 사항을 빠르게 확인할 수 있어, 타이밍과 움직임을 반복적으로 조정하는 모션 디자인 작업에 유리합니다.

렌더링을 오래 기다리기보다 화면에서 즉시 반응을 보며 시스템을 설계하는 흐름에 가깝습니다.

---

## 데이터 기반 모션

Cavalry는 CSV, JSON, Google Sheets, 이미지 데이터 같은 외부 데이터를 애니메이션에 연결하는 워크플로우를 제공합니다.

숫자, 텍스트, 이미지, 색상 같은 데이터를 기반으로 그래픽을 바꾸거나 여러 버전의 결과물을 자동으로 만들 수 있습니다.

버전이 많은 캠페인, 지역별 광고, 데이터 시각화, 스포츠 그래픽처럼 반복과 변형이 많은 작업에서 강점이 큽니다.

---

## 텍스트와 타이포그래피 애니메이션

Cavalry는 글자, 단어, 줄 단위로 애니메이션을 제어하는 타이포그래피 작업에 잘 맞습니다.

텍스트 요소를 분리하고, 각 단위에 지연, 변형, 반복 규칙을 적용해 키네틱 타이포그래피나 정보형 모션 그래픽을 만들 수 있습니다.

---

## Dynamic rendering

Cavalry는 하나의 장면에서 여러 출력물을 만들어야 하는 상황을 고려한 렌더링 흐름을 제공합니다.

데이터나 토큰을 활용해 이름, 문구, 크기, 버전이 다른 결과물을 자동으로 렌더링할 수 있어 대량 제작 작업에 적합합니다.

---

# Cavalry의 장점

## 1. 반복 작업을 시스템화한다

After Effects에서 레이어를 복제하고 키프레임을 반복해서 수정해야 하는 작업을 Cavalry에서는 규칙과 연결 관계로 만들 수 있습니다.

한 번 구조를 잘 잡아두면 색상, 텍스트, 데이터, 개수, 타이밍 변경에 훨씬 유연하게 대응할 수 있습니다.

---

## 2. 데이터와 모션을 자연스럽게 연결한다

단순한 그래픽 애니메이션을 넘어 데이터에 따라 달라지는 시각 결과물을 만들 수 있습니다.

브랜드 캠페인, 실시간 정보 그래픽, 이벤트 영상, 광고 버전 관리처럼 데이터가 들어가는 모션 작업에 유용합니다.

---

## 3. 2D 모션에 3D식 사고를 가져온다

Cavalry는 2D 툴이지만 리깅, 제약, 인스턴싱, 절차형 제어처럼 3D 모션 툴에서 익숙한 개념을 많이 활용합니다.

그래서 복잡한 그래픽 시스템을 구축하는 모션 디자이너에게 좋은 실험 공간이 됩니다.

---

# 주의할 점

Cavalry는 After Effects를 완전히 대체하는 범용 합성 툴이라기보다, procedural 2D motion과 data-driven workflow에 강한 전문 도구입니다.

팀 전체가 Adobe After Effects 플러그인, 템플릿, 합성 워크플로우에 깊게 묶여 있다면 도입 초기에 학습 비용과 파이프라인 조정이 필요합니다.

또한 절차형 접근은 강력하지만, 간단한 일회성 애니메이션에는 구조를 설계하는 시간이 더 크게 느껴질 수 있습니다.

---

# Cavalry는 어떤 사람에게 적합할까?

- 반복 패턴이 많은 2D 모션 그래픽을 만드는 디자이너
- 키네틱 타이포그래피와 제너러티브 그래픽을 자주 만드는 사용자
- CSV, JSON, Google Sheets 기반의 데이터 애니메이션이 필요한 팀
- 여러 크기와 버전의 광고 영상을 자동으로 만들고 싶은 조직
- After Effects보다 절차형 제어에 강한 2D 모션 툴을 찾는 사람
- 모션 디자인에 리깅, 인스턴싱, 시스템 설계를 도입하고 싶은 제작자

---

# 마무리

Cavalry는 수작업 키프레임 중심의 2D 애니메이션을 절차형 시스템과 데이터 기반 제작 흐름으로 확장하는 도구입니다.

반복과 변형이 많은 모션 그래픽, 데이터 시각화, 브랜드 모션 시스템을 만드는 팀이라면 충분히 검토할 만한 선택지입니다.
