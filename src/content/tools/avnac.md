# Avnac이란?

Avnac은 브라우저에서 실행되는 오픈소스 디자인 에디터입니다.

포스터, 소셜 그래픽, 간단한 레이아웃 작업을 만들 수 있으며, 계정이나 클라우드 저장소에 의존하지 않고 로컬 중심으로 작업하는 흐름을 지향합니다.

핵심은 "가볍게 열고, 내 컴퓨터에 저장하면서, 바로 그래픽 작업을 만드는 것"입니다. Canva처럼 빠른 시각 콘텐츠 제작을 목표로 하지만, 오픈소스와 로컬 우선 구조가 차별점입니다.

---

# Avnac의 핵심 특징

Avnac은 복잡한 디자인 시스템 도구라기보다, 브라우저 기반 캔버스에서 텍스트, 도형, 이미지, 레이어를 조합하는 그래픽 편집기에 가깝습니다.

디자인 파일은 기본적으로 브라우저의 로컬 저장소에 보관되며, 결과물은 PNG로 내보낼 수 있습니다.

## 브라우저 기반 캔버스 에디터

Avnac은 설치 없이 웹 브라우저에서 디자인 작업을 시작할 수 있습니다.

텍스트, 도형, 이미지, 레이어를 배치하고 정렬하면서 포스터나 소셜 이미지 같은 단일 화면 그래픽을 만들 수 있습니다.

### 활용 예시

- 소셜 미디어 카드 제작
- 이벤트 포스터 시안 제작
- 간단한 마케팅 배너 제작
- 썸네일과 홍보 이미지 구성
- 로컬에서 빠르게 그래픽 초안 만들기
- 오픈소스 디자인 에디터 실험

---

## Local-first 저장 방식

Avnac은 로컬 우선 방식을 지향합니다.

작업 데이터는 기본적으로 사용자의 브라우저 환경에 저장되며, 별도의 계정 생성이나 클라우드 동기화 없이도 사용할 수 있습니다.

개인 작업이나 빠른 초안 제작처럼 외부 서비스에 파일을 올리고 싶지 않은 상황에서 장점이 있습니다.

---

## 레이어와 그래픽 요소 편집

Avnac은 텍스트, 도형, 이미지 같은 기본 그래픽 요소를 캔버스 위에 배치하고 편집할 수 있습니다.

레이어 기반으로 요소를 관리할 수 있어 포스터, 배너, 카드형 이미지처럼 여러 요소가 겹치는 디자인을 구성하기 좋습니다.

---

## QR 코드와 PNG export

Avnac은 QR 코드 생성과 PNG 내보내기를 지원합니다.

이벤트 안내, 홍보물, 링크 공유용 이미지처럼 QR 코드가 들어가는 그래픽을 빠르게 만들 수 있고, 완성된 결과는 이미지 파일로 저장해 사용할 수 있습니다.

---

# Avnac의 장점

## 1. 가볍고 접근하기 쉽다

브라우저에서 바로 실행할 수 있어 무거운 데스크톱 디자인 툴을 열지 않아도 됩니다.

간단한 그래픽이나 초안을 빠르게 만들 때 진입 장벽이 낮습니다.

---

## 2. 오픈소스 기반이다

Avnac은 오픈소스 프로젝트로 공개되어 있어 코드와 동작 방식을 직접 확인할 수 있습니다.

팀이나 개인 개발자가 필요에 맞게 실험하거나 확장하기 좋은 구조입니다.

---

## 3. 로컬 작업 흐름에 잘 맞는다

기본 사용 흐름이 로컬 중심이기 때문에, 계정 기반 SaaS에 모든 작업물을 올리는 방식이 부담스러운 사용자에게 적합합니다.

빠른 개인 작업, 실험용 디자인, 내부 초안 제작에 실용적입니다.

---

# 주의할 점

Avnac은 Canva나 Figma처럼 대규모 협업, 템플릿 마켓, 고급 디자인 시스템 관리까지 제공하는 성숙한 제품은 아닙니다.

복잡한 브랜드 작업, 팀 협업, 정교한 프로토타입, 다양한 export 포맷이 필요한 경우에는 기능이 부족하게 느껴질 수 있습니다.

또한 로컬 저장 방식은 편리하지만, 브라우저 데이터 삭제나 기기 변경 상황에 대비해 결과물을 주기적으로 export하는 습관이 필요합니다.

---

# Avnac은 어떤 사람에게 적합할까?

- 오픈소스 Canva 대안을 찾는 사용자
- 계정 없이 브라우저에서 빠르게 그래픽을 만들고 싶은 사람
- 포스터, 카드뉴스, 소셜 이미지 초안을 자주 만드는 팀
- 로컬 우선 디자인 도구를 선호하는 사용자
- 디자인 에디터 구현 사례를 살펴보고 싶은 개발자
- QR 코드가 들어간 간단한 홍보 이미지를 만드는 사용자

---

# 마무리

Avnac은 로컬 우선, 오픈소스, 브라우저 기반이라는 방향성이 뚜렷한 그래픽 디자인 에디터입니다.

무거운 전문 디자인 툴보다 빠르게 열고 간단한 시각 콘텐츠를 만들고 싶을 때 실용적인 선택지가 될 수 있습니다.
