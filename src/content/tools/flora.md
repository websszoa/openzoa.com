# Flora란?

Flora는 생성형 AI 작업을 노드 기반 캔버스에서 연결해 탐색하는 이미지와 비디오 제작 도구입니다.

프롬프트, 생성 결과, 변형, 참조 이미지를 흐름으로 정리하면서 여러 시각 아이디어를 체계적으로 실험할 수 있습니다.

---

# Flora의 핵심 특징

## 노드 기반 생성 캔버스

Flora는 하나의 프롬프트 결과만 보는 방식이 아니라, 생성 과정 자체를 캔버스에 펼쳐놓고 관리합니다.

이미지 변형, 스타일 비교, 참조 연결을 시각적으로 추적할 수 있어 복잡한 아이데이션에 유리합니다.

### 활용 예시

- 콘셉트 아트 방향 탐색
- 광고 비주얼 변형 비교
- 이미지와 비디오 아이디어 정리
- 브랜드 스타일 실험
- 생성 과정의 버전 관리

---

## 분기와 반복

좋은 결과를 기준으로 여러 방향을 분기하고 다시 조합할 수 있습니다.

생성형 AI 작업에서 흔히 생기는 결과물 산발 문제를 줄이고, 어떤 시도가 효과적이었는지 되짚기 쉽습니다.

---

# 주의할 점

노드 기반 작업은 강력하지만 처음에는 일반 채팅형 생성 도구보다 복잡하게 느껴질 수 있습니다.

작업 규모가 작다면 단순 이미지 생성 도구가 더 빠를 수 있습니다.
